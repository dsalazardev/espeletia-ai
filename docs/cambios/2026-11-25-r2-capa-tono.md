Ajustes trae «Cómo responde Fray»: normal, corto, con detalle o para niños. Si una ficha tiene la variante que escribió R1 (`variantes.corta|larga|ninos` en chat.json), se muestra esa; si no, la original. La fuente y el dato no cambian.

Las preguntas urgentes siempre usan la variante corta y, si existe, una frase de empatía aprobada (`empatia` en chat.json). Cuando sale una variante, la tarjeta ofrece «Ver la respuesta completa».

No se genera ni se reformula texto. chat.json todavía no trae variantes, así que la prueba (`pruebas/tono.py`) las inyecta. Spec: docs/specs/2026-11-24-capa-tono.md (issue #21).
